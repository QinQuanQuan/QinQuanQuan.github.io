这里是 **QinQuanQuan** 的个人站点，部署在 GitHub Pages 上，通过自定义域名 `qinquanquan.com` 访问。

## 为什么写

互联网上的收藏夹只会越堆越多，而笔记写下来、连起来，才会真正变成自己的东西。所以这个站点被设计成一座「数字花园」：不追求一次性写完，而是允许内容慢慢生长、不断修订。

## 内容范围

| 板块 | 说明 |
| --- | --- |
| 笔记 | 技术学习、工具速查、读书摘录 |
| 项目 | 正在做的事、阶段目标与复盘 |
| 指南 | 写作、发布、部署等流程文档 |

## 技术实现

本站基于 [Astro](https://astro.build) 静态站点框架，主题使用 Astro 官方主题库中的免费模板 **Veka**：

- 零配置路由：目录即导航，新增 Markdown 文件自动出现在侧边栏。
- 本地全文搜索：构建期生成索引，无第三方服务。
- 极简样式：Tailwind CSS v4，深浅色自动切换。

具体的搭建过程记录在 [[astro-veka-setup]] 里。
